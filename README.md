# 🎵 Content Verse — Create, Collect, and Monetize Digital Content

**Content Verse** is a decentralized content platform that empowers creators to **mint, monetize, and share their work** on the Stellar blockchain. Built with **React + TypeScript + Vite + Supabase**, it bridges Web2 usability with Web3 ownership.

---

## 🚀 Features

- 🖼️ **Create & Mint Content:** Creators can publish articles, music, or digital art and mint them as unique on-chain assets.  
- 💰 **Buy & Collect:** Users can purchase content using XLM, supporting their favorite creators directly.  
- 🧾 **Own Your Purchases:** Every purchase is recorded on-chain — full transparency, no middlemen.  
- 👤 **Creator Profiles:** Showcase your minted content and see what you’ve collected.  
- 🔐 **Wallet-Based Login:** Seamless authentication via Stellar wallets.  
- 🪙 **Content Monetization:** Automatic revenue flow to creators on every purchase.

---

## 🧩 Tech Stack

| Category | Tools |
|-----------|-------|
| Frontend | React, TypeScript, Vite, Tailwind CSS |
| Backend | Supabase (PostgreSQL + Auth + Storage) |
| Blockchain | Base (Zora Factory) |
| Auth | Wallet-based authentication Privy |
| Hosting | Vercel / Netlify |

## ⚙️ Installation

```bash
# Clone this repository
git clone https://github.com/Miracle656/mintverse.git
cd mintverse

# Install dependencies
npm install

# Run the app locally
npm run dev
```

---

## 🔧 Environment Variables

Create a `.env` file in the root directory and add the following:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
VITE_PRIVY_APP_ID=
VITE_ZORA_API_KEY=
```

---

## 🧠 How It Works

1. **Creators** upload and mint their content (stored in Supabase, registered on Stellar).  
2. **Users** browse, purchase, and unlock premium content.  
3. **Ownership** and transaction details are permanently recorded.  
4. **Profile page** dynamically displays created and purchased content.
